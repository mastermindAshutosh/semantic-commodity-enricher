Semantic Commodity Enricher A Neuro-Symbolic Pipeline for Autonomous Reference Data Management

This project implements a "Zero Maintenance" enrichment pipeline that transforms static, "dumb" commodity strings (e.g., "Brent Crude") into intelligent, interconnected entities. By combining Knowledge Graphs (RDF/SPARQL) for precision with Vector Embeddings (AI) for intuition, the pipeline autonomously: Resolves Identity: Links internal IDs to canonical Wikidata entities. Standardizes Physics: Maps units (Barrels, Ounces) to the QUDT Ontology for automated conversion. Enables Fuzzy Search: Uses FAISS and SentenceTransformers to map slang queries (e.g., "Yellow Metal") to correct assets. It represents the "Fourth Wave" of data architecture: moving beyond SQL and Vectors to fully integrated Semantic Pipelines.
